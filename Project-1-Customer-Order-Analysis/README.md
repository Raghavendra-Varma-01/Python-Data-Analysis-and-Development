# Project 1 — Customer Order Analysis Using Python

## Objective

Analyze a predefined e-commerce customer-order dataset using Python data structures and control structures to classify customers, examine product categories, and generate business insights.

## Files

- **`Customer_Order_Analysis.ipynb`** — Jupyter Notebook containing the Python implementation, displayed outputs, analysis, and conclusion.
- **`Customer_Order_Analysis_Report.pdf`** — formatted course-end project report.

## Python Concepts Used

- Lists and tuples to store customer and order information
- Dictionaries to organize orders, product categories, spending, and category revenue
- Sets and set operations to identify unique products and cross-category customers
- Loops and conditional statements for customer spending classification
- List comprehensions and sorting for customer analysis

## Analysis Included

- Customer spending totals and high-, moderate-, and low-value classifications
- Revenue by product category
- Unique products and product purchase frequency
- Customers purchasing electronics
- Top three highest-spending customers
- Customers purchasing across multiple categories

## Key Results in the Notebook

- 9 customers and 20 orders analyzed
- 13 unique products across 3 product categories
- Electronics revenue: **$2,550.00**
- Home Essentials revenue: **$1,310.00**
- Clothing revenue: **$340.00**
- Most frequently purchased product: **T-Shirt (5 purchases)**
- Top three spenders: **David ($1,040.00), Alice ($880.00), Grace ($760.00)**

## How to Run

1. Open `Customer_Order_Analysis.ipynb` in Jupyter Notebook, JupyterLab, or VS Code with the Jupyter extension.
2. Run the cells from top to bottom.

The notebook uses Python's standard library and does not require external packages for the analysis shown.
