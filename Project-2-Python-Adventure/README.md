# Project 2 — Python Adventure Game

## Objective

Build an interactive, text-based command-line adventure game in Python. The player explores a dark forest or a mysterious cave, makes decisions, and attempts to find a legendary treasure.

## Files

- **`adventure_game.py`** — complete Python source code for the game.
- **`Adventure_Game_Report.pdf`** — course-end report describing the implementation, GitHub Copilot assistance, challenges, enhancements, and test outputs.

## Features

- Personalized welcome using the player's name
- Choice between the dark forest and mysterious cave
- Decision-based paths with winning and game-over outcomes
- Replay option after each attempt
- Separate functions for the game start and each path

## Python Concepts Used

- Functions
- Variables and user input/output
- `if` / `elif` / `else` conditionals
- `while` loop and replay logic

## How to Run

Requires Python 3.

```bash
python adventure_game.py
```

## Test Scenarios Documented

The report includes successful and unsuccessful forest/cave paths, plus replay and exit scenarios.
