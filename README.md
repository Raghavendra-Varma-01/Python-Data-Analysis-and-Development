# Python Data Analysis and Development

This repository contains two completed Python course-end projects demonstrating practical applications of Python programming, data structures, business analysis, and interactive application development.

## Projects

### 01. Customer Order Analysis Using Python

**Objective:** Analyze customer orders for an e-commerce business using Python's built-in data structures and control structures to identify purchasing patterns and generate business insights.

**Key Features:**
- Customer order management using lists, tuples, and dictionaries
- Product categorization using dictionaries and sets
- Customer spending calculation and classification
- Category-wise revenue analysis
- Unique product identification and purchase frequency
- Identification of electronics customers
- Top three highest-spending customers
- Cross-category customer purchasing analysis

**Python Concepts Used:**
- Lists and Tuples
- Dictionaries and Sets
- Loops and Conditional Statements
- List Comprehensions
- Sorting and Set Operations

**Key Results:**
- 9 customers and 20 orders analyzed
- 13 unique products across 3 categories
- Electronics generated $2,550 in revenue
- T-Shirt was the most frequently purchased product, with 5 purchases
- David, Alice, and Grace were the top three highest-spending customers

**Project Files:**
- `Customer_Order_Analysis.ipynb` – Python implementation and analysis
- `Customer_Order_Analysis_Report.pdf` – Detailed project report

[Open Project 1](./Project-1-Customer-Order-Analysis/)
